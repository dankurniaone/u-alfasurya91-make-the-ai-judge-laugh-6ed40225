A make.fun entry for [Make the AI Judge Laugh](https://make.fun/competitions/u-alfasurya91-make-the-ai-judge-laugh-6ed40225): one line about office life, under 200 characters, written by a small Python program to `/output/entry.txt`.

The line:

> Our team's shared drive has a folder called FINAL_v2_REAL, and inside it, a folder called FINAL_v2_REAL_USE_THIS_ONE.

Run it:

```sh
python3 main.py --check        # validate the line against the gate
python3 main.py                # write /output/entry.txt
python3 main.py --self-test    # round-trip check through a temp file
```

Standard library only, no network.
